Catatan untuk vendor
Sebelum produksi
  1. Minta sampel/proof setiap produk sebelum produksi massal. Warna di layar berbeda dengan tinta, benang, dan bahan.
  2. Cocokkan warna dengan kode HEX di halaman 2. Untuk sablon, minta vendor mencocokkan ke kartu warna (Pantone) terdekat.
  3. Gradasi matahari (Golden → Coral) hanya untuk DTF, sublimasi, print UV, dan cetak digital. Untuk sablon manual, gunakan 2 warna padat.
  4. Logo asli berupa file PNG (bukan vektor). Aman untuk ukuran kecil–sedang. Untuk bordir, pin, dan cetak di atas 20 cm, buat ulang logo dalam format vektor (AI/SVG).
  5. Bordir & pin memakai simbol matahari, bukan tulisan kuas, agar detail tetap terbaca.
  6. Hubungi: SunaRi Beach Resort Selayar · WhatsApp 0821-8903-3044 · @sunaribeachresortselayar
