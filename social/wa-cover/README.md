# Sampul WhatsApp Business: Mozaik Senja SunaRi

File: `sampul-whatsapp-business.png` · 2424 × 1362 px (16:9; 2× dari ukuran acuan 1211 × 681)

**Isi:** 55 foto senja milik SunaRi dari `assets/photos/senja/`, disusun dari golden hour (terang, kiri atas) ke afterglow (gelap, kanan bawah), dengan **hanya logo** di tengah (tanpa tulisan lain). Logo diwarnai gradasi senja (keemasan → jingga → coral) di atas panel cokelat gelap yang bentuknya mengikuti logo (memanjang, ±1,7 : 1). File logonya: `assets/logo-sunari-sunset.png`.

**Foto yang sengaja tidak dipakai:** 01, 02, 02b, 26 (ada cap tanggal); 58 (wajah tamu terlihat); 62, 63 (kemungkinan anak-anak); 69 (botol minuman); 41, 43, 46, 61, 67 (terlalu mirip dengan foto lain); 13, 34 (orang terlalu dekat ke kamera).

## Cara memasang
1. Buka **WhatsApp Business** → **Pengaturan** (iPhone) / **⋮ → Pengaturan** (Android) → **Alat bisnis** → **Profil bisnis**.
2. Ketuk area **sampul** di bagian atas profil (ikon kamera) → **Pilih foto** → pilih `sampul-whatsapp-business.png`.
3. Geser/atur supaya logo tetap di tengah → **Simpan**.

Foto profil (lingkaran) biasanya menutupi bagian bawah tengah sampul, jadi logo diletakkan sedikit di atas tengah. Kalau menu sampul belum muncul, perbarui aplikasi WhatsApp Business (fitur ini dirilis bertahap).

Build ulang: `python3 social/build_wa_cover.py && node social/render_wa_cover.js`
