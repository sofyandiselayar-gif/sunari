## Isi folder
| Folder | Isi | Untuk apa |
|---|---|---|
| `PNG/` | Semua desain, siap upload ke Instagram | Langsung posting |

| `CAPTION_REELS_TIKTOK.md` | Template caption Reels & TikTok per jenis konten | Copy-paste saat posting video |
| `RENCANA_STORY_10_HARI.md` | Jadwal story 20–29 Nov + isi stiker (desain di `PNG/10_Story_10_Hari`) | Panduan posting story |

| `preview-feed-instagram.png` | Contoh tampilan profil | Referensi urutan posting |

Ukuran: feed & carousel **1080 × 1350 px (4:5)**, story **1080 × 1920 px (9:16)**.

## Cara mengedit di Canva
1. Buka **canva.com** → klik **Upload** (atau *Buat desain* → *Impor file*).
2. Pilih file dari folder `CANVA_Import/`, misalnya `03_Carousel_Superior.pdf`.
3. Canva membuat desain baru. Setiap halaman PDF menjadi satu halaman Canva.
4. Klik teks untuk mengganti isi (jam senja, tanggal, nomor WA, judul). Foto bisa diganti dengan cara *drag & drop* foto baru ke atas foto lama.
5. Unduh hasil: **Bagikan → Unduh → PNG**, centang "semua halaman".

**Font yang dipakai** (keduanya tersedia gratis di Canva):
- Judul: **Playfair Display** (Regular & Italic)
- Teks & label: **Montserrat** (Regular / Medium)

Kalau setelah impor font terlihat berbeda, pilih teksnya lalu ganti font ke nama di atas.

**Warna brand** (masukkan sebagai *Brand Kit* di Canva):
